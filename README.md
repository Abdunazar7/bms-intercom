# BMS Intercom

Интеграция Home Assistant для вызывной панели Hikvision (DS-KV…). Всё в одном
месте: входящий вызов → полноэкранный/центрированный поп-ап с видео и **полным
двусторонним звуком** → кнопки **Ответить / Открыть / Сбросить**, как на телефоне.

Двусторонний звук работает «из коробки»: видео и приём звука идут через
**встроенный в Home Assistant go2rtc**, а микрофон оператора — напрямую через
**ISAPI** панели. **Не нужны** ни go2rtc-аддон, ни правки `configuration.yaml`,
ни browser_mod / webrtc-card — поп-ап встроен и подгружается автоматически.

## Возможности

- 📞 **Автоматический поп-ап** при звонке на панель — на любом открытом дашборде.
- 📹 **Видео + входящий звук** с панели (RTSP → WebRTC через встроенный go2rtc).
- 🎙️ **Микрофон → панель** через native ISAPI two-way audio (без go2rtc-аддона). Включён по умолчанию, как телефонный разговор; отключается кнопкой.
- 🔔 **Звук звонка** (встроенный, зацикленный).
- ✅ **Ответить / Сбросить** — по ISAPI; панель «понимает», что трубку подняли/положили.
- 🔒 **Открыть** — реле двери; вызов завершается автоматически.
- 👁️ **Просмотр (idle)** — переключатель открывает окно с живым видео и кнопками Открыть/Звук без звонка.
- 🧪 **Демо-режим** — виртуальная панель для настройки без оборудования.

## Установка

### Через HACS (рекомендуется)
1. HACS → Интеграции → ⋮ → **Custom repositories** → добавьте этот репозиторий (тип *Integration*).
2. Установите **BMS Intercom** и перезапустите Home Assistant.

### Вручную
Скопируйте `custom_components/bms_intercom` в `config/custom_components/` и перезапустите HA.

## Настройка

**Настройки → Устройства и службы → Добавить интеграцию → BMS Intercom**, затем
выберите режим:

### Демо-режим
Виртуальная панель без оборудования. Появятся сенсор «Вызов» и кнопки, включая
**Симулировать звонок** — нажмите, чтобы увидеть весь сценарий (поп-ап, видео,
ответ, дверь, сброс).

### Реальная панель
Укажите параметры панели DS-KV:

| Поле | Значение |
|------|----------|
| IP-адрес панели | например `192.168.1.50` |
| Логин / Пароль | учётная запись ISAPI (обычно `admin`) |
| HTTP порт (ISAPI) | по умолчанию `80` |
| RTSP порт | по умолчанию `554` |
| Номер реле двери | по умолчанию `1` |

Интеграция проверит связь с панелью при добавлении.

## Что создаётся

Устройство «Домофон» с сущностями:

| Сущность | Назначение |
|----------|-----------|
| `camera` Видео | поток с панели |
| `binary_sensor` Вызов | активен во время звонка (атрибут `call_state`: idle/ringing/answered) |
| `button` Ответить / Сбросить / Открыть дверь | управление |
| `switch` Просмотр | открыть/закрыть окно живого просмотра без звонка |
| `button` Симулировать звонок | только в демо-режиме |

## Двусторонний звук — автоматически, без go2rtc-аддона

- **Видео и приём звука** (посетитель → оператор) идут через встроенный в Home
  Assistant **go2rtc** — настраивать ничего не нужно.
- **Микрофон** (оператор → панель) интеграция отдаёт напрямую через **ISAPI
  two-way audio** панели: браузер кодирует звук в G.711 µ-law и шлёт его по
  WebSocket, интеграция передаёт его панели. go2rtc-аддон и `configuration.yaml`
  для этого **не нужны**. Кодек панели интеграция при настройке сама ставит в
  G.711.

Микрофон включён по умолчанию (как телефонный разговор) и отключается кнопкой.

Браузер разрешает микрофон только в защищённом контексте (HTTPS). Поэтому
интеграция **сама поднимает локальный HTTPS** — ничего настраивать не нужно:

- при запуске генерируется самоподписанный сертификат (SAN на все локальные
  адреса и имена Home Assistant);
- поднимается лёгкий reverse-proxy на отдельном порту (по умолчанию `8443`),
  который проксирует весь HA (страница, WebSocket, видео);
- поп-ап вызова, открытый по http, сам показывает кнопку **«Открыть по HTTPS»**
  на `https://<ваш-адрес>:8443`.

От вас — только **IP/логин/пароль панели**. Единственное, что нельзя
автоматизировать, — браузер один раз попросит принять самоподписанный
сертификат («Дополнительно → Перейти»).

Порт можно сменить, а также задать готовый внешний HTTPS-адрес (Nabu Casa и т.п.)
в **Настройки → Устройства и службы → BMS Intercom → Настроить**. Если хотите
HTTPS **без предупреждений** (локальный доверенный сертификат) — см.
[docs/local-https.md](docs/local-https.md).

## Как это устроено

```
Вызывная панель Hikvision
   ├── RTSP  ──► встроенный go2rtc (в HA) ──► camera ──► поп-ап (видео + входящий звук)
   ├── ISAPI ──► статус вызова (опрос) ──► binary_sensor ──► поп-ап (автопоказ)
   │             ответ / сброс / дверь  ◄── кнопки поп-апа
   └── ISAPI two-way audio  ◄── микрофон оператора (G.711, через WebSocket интеграции)
```

> Проверено на физической **Hikvision DS-KV6113**: двусторонний звук работает
> через встроенный go2rtc (видео) + native ISAPI (микрофон), без go2rtc-аддона
> и правок `configuration.yaml`.

Весь текст в интерфейсе (поп-ап, подписи) использует **родной шрифт Home
Assistant** — ничего не бандлится.

Иконка и логотип интеграции лежат в `custom_components/bms_intercom/brand/` и
показываются Home Assistant напрямую (требуется HA 2026.3+; PR в каталог
home-assistant/brands не нужен).
