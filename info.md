# BMS Домофон (Hikvision)

Вызывная панель Hikvision DS-KV в Home Assistant: входящий вызов → всплывающее
окно с видео и звуком звонка → **Ответить / Сбросить / Открыть дверь**.
Микрофон по умолчанию выключен (push-to-talk).

- Поп-ап встроен — без browser_mod и правки дашборда.
- Видео через встроенный go2rtc, управление по ISAPI.
- **Демо-режим** для настройки без оборудования.

После установки: **Настройки → Устройства и службы → Добавить интеграцию → BMS Домофон**.
